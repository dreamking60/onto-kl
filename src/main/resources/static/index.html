SPARQL 查询

前缀 : rdf: rdfs: owl: xsd: 已由服务端预绑定；支持 SELECT / ASK / CONSTRUCT / DESCRIBE。

选择示例或输入 SPARQL 后运行，结果会显示在这里。

推理

业务规则（Jena RuleReasoner，前向 RETE）+ OWL 推理闭包（OWL_MEM_MINI_RULE_INF）。首次运行会计算闭包，之后复用缓存。

点击「运行推理」查看推导结果与统计信息。

推导解释

输入个体 IRI，查看每条推导语句的规则链和前提。
